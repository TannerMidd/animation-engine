# TITLE  
INT. OFFICE BREAK ROOM - MORNING  
SARAH  
(deadpan)  
Sarah?

MARK  
(looking up from a coffee machine)  
Yes?  

SARAH  
(deadpan)  
The building’s been sold.  

MARK  
(blank)  
To who?  

SARAH  
(deadpan)  
To… itself.  

MARK  
(confused)  
What do you mean, itself?  

SARAH  
(deadpan)  
The buyer’s name is “The Building.” The address is the same as the building.  

MARK  
(suspicious)  
That’s not a real company.  

SARAH  
(deadpan)  
It’s a shell company.  

MARK  
(weary)  
Shell companies don’t own buildings.  

SARAH  
(deadpan)  
This one does.  

MARK  
(deflated)  
How do you know?  

SARAH  
(deadpan)  
I called the legal department. They’re… busy.  

MARK  
(puzzled)  
Busy with what?  

SARAH  
(deadpan)  
They’re trying to figure out if the building’s a person now.  

MARK  
(sceptical)  
Why would it be a person?  

SARAH  
(deadpan)  
The paperwork says it has a Social Security number.  

MARK  
(alarmed)  
A Social Security number?  

SARAH  
(deadpan)  
It’s… not valid.  

MARK  
(drained)  
So what happens now?  

SARAH  
(deadpan)  
We keep working.  

MARK  
(quiet)  
And the rent?  

SARAH  
(deadpan)  
It’s… unpaid.  

MARK  
(surprised)  
Unpaid?  

SARAH  
(deadpan)  
The building’s now its own landlord.  

MARK  
(quiet)  
So we’re… tenants of ourselves?  

SARAH  
(deadpan)  
Technically.  

MARK  
(satisfied)  
Well. That’s… something.  

SARAH  
(calm)  
We should make coffee.  

MARK  
(grinning)  
Agreed.  

[BEAT 1500]  
SARAH  
(deadpan)  
The machine’s still working.  

MARK  
(pleased)  
Good.  

[BEAT 1000]  
SARAH  
(monotone)  
I’ll get the mugs.  

MARK  
(blank)  
I’ll get the milk.  

[BEAT 2000]  
SARAH  
(quiet)  
This is… normal.  

MARK  
(warm)  
It is.  

[BEAT 800]
